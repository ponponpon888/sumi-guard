# SUMI Guard 読み取り専用CLI試験（2026-10-03）

## 結論

架空データだけを使い、保存済み記録の一覧、詳細、保存状態を表示するCLIをWindows PowerShell 5.1で
検証した。正常記録、記録なし、参照切れ、保持期限による削除、アクセス失敗を区別できた。本文の
復号は呼ばず、CLI実行前後の保存内容は一致した。

既存Codex試験、実際の開発コマンド、通常の開発ログは実行・収集していない。恒久フック、常駐処理、
監査設定も変更していない。

## 条件

- 対象: `tools/Show-SumiGuardRecords.ps1`
- 実行環境: Windows PowerShell 5.1
- 入力: 実行時に生成した架空本文と合成メタデータだけ
- 保存先: `%TEMP%` 配下の試験専用ディレクトリ
- 終了時: 試験専用ディレクトリを削除、残存なし
- 本文読戻しAPI: 未呼出し
- Codex実行試験: 未実施

## 結果

| ケース | 結果 | 確認内容 |
|---|---|---|
| 正常記録 | 成功 | `SUCCEEDED`、暗号化保存済み、候補1件、`INFERRED_MATCH` |
| 記録なし | 成功 | `NO_RECORD`。空ストアにロックファイルを新規作成しなかった |
| 参照切れ | 成功 | `REFERENCE_MISSING` を「参照切れ」と表示 |
| 期限切れ | 成功 | `DELETED_BY_RETENTION` を「保持期限により削除」と表示 |
| アクセス失敗 | 成功 | 非0終了、`読み取り失敗`、`COLLECTION_FAILED`。例外本文なし |
| 保存状態 | 成功 | 使用容量、CLI指定上限、保持期間、参照切れ、期限切れ、取得失敗を表示 |
| 読み取り不変性 | 成功 | 前後のファイル集合、サイズ、更新時刻、SHA-256が一致 |
| 秘密情報非表示 | 成功 | 一覧、詳細、保存状態、失敗表示、標準エラーに架空本文なし |

合成試験の4集約項目はすべて合格した。アクセス失敗ケースの試験ランナー上の終了コードは1、標準
エラーは空だった。この結果は合成試験についての値である。2026-10-03の実フック試験でCLI標準
エラーが非空だった件は、内容を保存していないため原因未特定のままであり、推測で補完していない。

## 読み取り専用性

既存ロックがあるストアではExecutionAdapterの公開読取APIを優先した。公開APIがロックを
`OpenOrCreate` で開くため、ロックがまだない空ストアではversion 1メタデータの読取専用
フォールバックを使用した。これにより、記録なしの照会でも新規ファイルを作らなかった。

容量集計では管理対象 `.sgb` の固定ヘッダーだけを読み、暗号化ペイロードを復号しなかった。
自動削除と修復は実行していない。
